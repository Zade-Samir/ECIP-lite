FAQ

Frequently Asked Questions

Does ECIP send any source code to external cloud servers? ▼
No. ECIP is designed specifically for zero-trust and privacy-sensitive codebases. All AST parsing, vector embedding generation, BM25 indexing, and LLM inference run strictly on your local machine or self-hosted server cluster.
Which local LLMs does ECIP support? ▼
ECIP supports any model running on Ollama, LM Studio, or OpenAI-compatible local API servers. Popular recommended choices include Qwen 2.5 Coder (7B / 14B / 32B), DeepSeek-Coder-V2, and Llama 3.1.
How does ECIP handle large repositories with thousands of files? ▼
ECIP uses SHA-256 hash tracking during project scanning to skip unchanged files. Only modified files are re-parsed and re-embedded, allowing fast incremental index updates.
Is ECIP free and open-source? ▼
Yes! ECIP Lite is licensed under the permissive MIT Open Source License. You can modify, self-host, and integrate it into commercial products without restrictions.
